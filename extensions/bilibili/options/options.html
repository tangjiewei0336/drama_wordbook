插件设置

插件通过 http 连本机的 sidecar（默认端口 17321），不直接连 Electron 窗口；请先启动桌面 UNI并保持 Sidecar 在线。
默认推荐 http://127.0.0.1:17321。若填写 localhost，部分系统会优先走 IPv6 导致连不上；保存时会自动改成 127.0.0.1。修改为非本机回环地址时保存会弹出权限请求。
默认 0.65，表示仅识别视频画面的下方 35% 区域。
默认 0.5：字幕带上半用于中文，下半用于日语。
示例：mac 建议 Command + E（若冲突可改 Command + Shift + S）；Windows 建议 Ctrl + Shift + S。
