# B 站插件 POC 使用说明

## 1. 加载插件

1. 打开 Chrome `chrome://extensions/`
2. 开启「开发者模式」
3. 选择「加载已解压的扩展程序」
4. 选择目录：`extensions/bilibili`

## 2. 使用步骤

1. 先启动本地 sidecar 服务（端口 `17321`）
2. 打开任意 B 站播放页
3. 点击插件图标
4. popup 会显示「最近添加词语」列表（持久化保存）
5. 可用按钮：
   - 「同步播放」：同步当前播放上下文
   - 「统计界面」：打开内置统计页（双视图）
   - 「设置」：打开插件设置页

## 额外快捷键触发

- 默认快捷键：
  - mac: `Command + E`
  - Windows/Linux: `Ctrl + Shift + S`
- 在 B 站页面可直接触发流程：自动暂停 -> 截图 + OCR + 分词 -> 网页内弹窗勾选词条
- 可在插件设置页自定义“页面内截图快捷键”
- 也可在 Chrome 扩展快捷键设置页（`chrome://extensions/shortcuts`）自定义命令快捷键
- 若 `Command + E` 无法触发，建议改为 `Command + Shift + S`（浏览器保留键可能冲突）

## 3. 预期结果

- 截图键触发后会弹出网页内词典添加窗口
- 可勾选分词并输入释义，点击「添加到词典」后持久化到本地
- 点击插件图标可查看最近词条

> 截图 OCR 流程会先按 `video` 窗口裁剪，再按设置的字幕带比例二次裁剪，尽量收紧识别区域。
> 可开启「固定双语布局（上半中文，下半日语）」以进一步提高识别稳定性。

## 4. 常见问题

- 若提示 sidecar 错误：确认 `http://127.0.0.1:17321/health` 可访问
- 若当前页不是 `bilibili.com`：插件会拒绝执行
