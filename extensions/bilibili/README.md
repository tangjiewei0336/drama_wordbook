# B 站插件 POC 使用说明

## 1. 加载插件

1. 打开 Chrome `chrome://extensions/`
2. 开启「开发者模式」
3. 选择「加载已解压的扩展程序」
4. 选择目录：`extensions/bilibili`

## 2. 使用步骤

1. **先在本机开启 sidecar**（监听 `17321`，与桌面「UNI」里是同一进程）：请先**打开 Electron 桌面应用**保持运行（或开发者自行 `uvicorn` 同名服务）。插件用 **HTTP 访问 `127.0.0.1:17321` / `localhost:17321`**，不是通过「连上 Electron 窗口」工作。
2. 打开任意 B 站播放页
3. 点击插件图标
4. popup 会显示「最近添加词语」列表（持久化保存）
5. 可用按钮：
   - 「同步播放」：同步当前播放上下文
   - 「统计界面」：打开内置统计页（双视图）
   - 「设置」：打开插件设置页

## 额外快捷键触发

- 默认快捷键：
  - mac: `Command + E`
  - Windows/Linux: `Ctrl + Shift + S`
- 在 B 站页面可直接触发流程：自动暂停 -> 截图 + OCR + 分词 -> 网页内弹窗勾选词条
- 可在插件设置页自定义“页面内截图快捷键”
- 也可在 Chrome 扩展快捷键设置页（`chrome://extensions/shortcuts`）自定义命令快捷键
- 若 `Command + E` 无法触发，建议改为 `Command + Shift + S`（浏览器保留键可能冲突）

## 3. 预期结果

- 截图键触发后会弹出网页内词典添加窗口
- 加载弹窗会显示当前步骤：截图准备、字幕裁切、OCR、大模型修正、分词查词
- 可勾选分词并输入释义，点击「添加到词典」后持久化到本地
- 如果手动修改「日语例句」，弹窗会自动重新分词并刷新词块
- 点击插件图标可查看最近词条

> 截图 OCR 流程会先按 `video` 窗口裁剪，再按设置的字幕带比例二次裁剪，尽量收紧识别区域。
> 可开启「固定双语布局（上半中文，下半日语）」以进一步提高识别稳定性。
> 桌面设置 -> OCR 修正可开启 GLM 后处理，支持 `GLM-4.7` 与 `GLM-4.7-FlashX`，用于修正促音、中日语错位和背景乱码。
> 字幕自动模式不会调用 GLM 后处理，避免自动识别循环被网络模型请求阻塞。

## 4. 常见问题

- 「连不上 Electron」：插件实际是连 **`http://127.0.0.1:17321`（本地 sidecar）**。请先在桌面客户端里确认 **Sidecar 在线**（或浏览器能打开 `/health`，见下一条）。
- 若提示 sidecar / fetch 被拒绝：先到插件 **设置** 里核对「本地 sidecar 地址」（可试 **`http://localhost:17321`** 替换 `127.0.0.1`）；改完点后 **移除并重新「加载已解压的扩展程序」** 以使 `manifest.json` 里的网络权限生效。
- 若在浏览器里打不开 `health`：**桌面应用自带的 sidecar 未启动**。需先修好桌面侧的 sidecar（或开发模式另行启动 sidecar），再刷新 B 站页重试。
- 若本地 sidecar **不在默认地址**（改成了局域网 IP 等）：在设置里写入完整 `http(s)://主机:端口` 前缀，保存时按提示授予「访问网站」权限。
- 自检：在浏览器新标签访问 `http://127.0.0.1:17321/health` 或 `http://localhost:17321/health`，应返回 JSON。
- 若当前页不是 `bilibili.com`：插件会拒绝执行
