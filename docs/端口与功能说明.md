# Drama Wordbook 端口与功能说明

## 固定端口

所有本地开发端口固定如下，避免服务自动换端口后扩展或桌面端连错：

| 模块 | 地址 | 用途 |
| --- | --- | --- |
| Desktop Vite | `http://127.0.0.1:4173` | React/Electron 开发预览 |
| Sidecar | `http://127.0.0.1:17321` | 本地 OCR、分词、词典、词条与句子数据 |
| Sync Server | `http://127.0.0.1:18321` | 本地调试云同步服务 |

端口占用时请先停掉占用进程，不要让 Vite/Uvicorn 自动改端口。浏览器扩展和桌面端都固定访问 `127.0.0.1:17321`。

## 启动命令

Sidecar：

```bash
cd apps/sidecar
uvicorn app.main:app --host 127.0.0.1 --port 17321 --reload
```

Sync Server：

```bash
cd apps/server
uvicorn app.main:app --host 127.0.0.1 --port 18321
```

Desktop：

```bash
cd apps/desktop
npm run dev
```

浏览器扩展无需启动端口，直接加载 `extensions/bilibili`，它会访问 Sidecar。

## 当前功能

### 浏览器扩展

- 在 B 站播放页截图并识别字幕。
- 支持页面内快捷键触发，默认 macOS 为 `Command + E`，Windows/Linux 为 `Ctrl + Shift + S`。
- 支持字幕带裁剪、固定双语布局、手动调整 OCR 文本。
- 支持多选词片段并自动拼接最终词形。
- 词典查询优先本地 JLPT 词库，外部词典作为兜底；网络不可用时会提示。
- 保存时可添加句子 tag，也可只保存句子。
- 支持字幕自动模式与 ASR 自动记录模式。
- 弹层中保存词条后写入 Sidecar，本地最近词条列表会同步更新。

### Sidecar

- 提供 OCR、日语分词、词典查询、音调、ASR 转写接口。
- 管理本地 SQLite 数据：词条、词头、句子、播放上下文、截图、设置。
- 支持句子视图：新增、更新、删除句子；删除句子会删除所有绑定单词。
- 支持按播放器、按时间、按句子查看数据。
- 支持 Space 数据：活跃图、最近在看、搭子分享、搭子申请。
- 支持云同步登录、注册、退出、推送/拉取、冲突解决、自动同步间隔设置。
- 个人信息仅在登录后可编辑，会同步到云端。

### Desktop

- 左侧支持按播放器、按时间、句子、Space、个人信息、运行状态切换。
- 句子视图支持剧照、文本编辑、朗读、词性分析、点词查释义、分享给搭子、删除句子。
- Space 页面展示最近 365 天活跃图；有搭子时上半格代表自己，下半格代表搭子，并显示月份刻度。
- Space 页面展示自己和搭子最近在看的番剧，数据来自本地和云端同步记录。
- 个人信息页未登录时隐藏个人信息编辑，仅显示登录与同步设置。
- 登录后可设置头像、昵称、主题色；可配置自动同步间隔。
- 运行状态页可查看 Sidecar 状态、ASR 模型状态和日志。

### Sync Server

- 提供账号注册、登录、退出和 bearer token 鉴权。
- 保存用户 profile、同步快照、同步提交历史。
- 支持增量变更查询、版本冲突检测、推送/拉取同步。
- 支持搭子申请、接受搭子、搭子状态、搭子最近在看、搭子活跃记录。
- 支持句子分享与未读分享查询。
- 提供本地调试管理页：`http://127.0.0.1:18321/admin?token=...`。

## 数据同步行为

- 本地登录云同步账号后才允许编辑个人信息。
- 登录或切换账号后，Sidecar 会从 `/me` 拉取当前账号 profile，避免沿用旧账号头像。
- 保存 profile 会同时写本地和云端。
- 同步推送会携带 profile、句子和词条快照。
- 搭子头像和 Space 数据来自云端用户 profile 与最新同步快照。

## 重要约定

- 公网同步服务器必须使用 HTTPS；本机调试允许 `http://127.0.0.1` 或 `http://localhost`。
- 截图文件保存在 Sidecar 本地数据目录，不提交到 git。
- 端口固定后，如果启动失败，优先检查占用端口的旧进程。
