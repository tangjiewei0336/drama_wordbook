# 剧集生词本（Win + macOS）跨平台项目骨架设计

## 1. 目标

构建一个在 Windows 和 macOS 上都可运行的桌面工具，支持：

- 全局快捷键截图当前剧集画面
- OCR 识别中文与日语字幕
- 对日语结果进行分词与词形还原
- 用户勾选生词后自动查词并写入生词本
- 将截图与例句（OCR 文本）关联到词条
- 与 B 站浏览器插件联动记录播放链接和进度

---

## 2. 技术栈定版

- **桌面客户端**：`Tauri 2` + `React` + `TypeScript`
- **本地语言服务（Sidecar）**：`Python 3.11+` + `FastAPI` + `Uvicorn`
- **OCR**：`PaddleOCR`（中日双语）
- **日语处理**：`SudachiPy` + `SudachiDict Core`
- **词典**：`JMDict`（离线）
- **本地存储**：`SQLite`
- **浏览器联动**：`Chrome/Edge 扩展 (Manifest V3)` + `localhost HTTP`

## 4. 进程与通信设计

### 4.1 进程模型

1. 用户按全局快捷键  
2. `desktop (Tauri/Rust)` 捕获截图并保存临时文件  
3. `desktop` 调用本机 `sidecar (FastAPI)` OCR / 分词 / 查词 API  
4. 前端弹出候选词勾选界面  
5. 用户确认后写入 SQLite，并关联截图及播放上下文  
6. 浏览器插件持续或按需上报 B 站播放上下文

### 4.2 通信边界

- **Desktop <-> Sidecar**：`HTTP localhost`（推荐 `127.0.0.1:17321`）
- **Extension <-> Sidecar**：`HTTP localhost`（增加来源校验与签名）
- **Desktop <-> Extension**：不直接通信，统一经 Sidecar 中转

## 5. API 协议（MVP）

### 5.1 健康检查

- `GET /health`
- 返回服务版本、OCR 模型状态、词典加载状态

### 5.2 OCR

- `POST /ocr/recognize`
- 入参：
  - `image_path` 或 `image_base64`
  - `languages: ["ja", "zh"]`
- 出参：
  - `ja_lines[]`
  - `zh_lines[]`
  - `raw_blocks[]`（可用于调试）

### 5.3 日语分词

- `POST /ja/tokenize`
- 入参：
  - `text`
  - `mode`（A/B/C，可先默认 C）
- 出参：
  - `tokens[]`：`surface / dictionary_form / pos / reading`

### 5.4 词典查询

- `POST /dict/lookup`
- 入参：
  - `lemma`（优先 dictionary_form）
- 出参：
  - `entries[]`：释义、词性、读音、常见度信息

### 5.5 播放上下文上报（插件）

- `POST /playback/context`
- 入参：
  - `platform`（固定 `bilibili`）
  - `url`
  - `title`
  - `current_time`
  - `duration`
  - `bvid/aid/cid/ep_id/p`（可选）
- 出参：
  - `context_id`

### 5.6 生词入库

- `POST /vocab/add`
- 入参：
  - `word`
  - `lemma`
  - `reading`
  - `meanings[]`
  - `example_ja`
  - `example_zh`（可选）
  - `screenshot_path`
  - `playback_context_id`（可选）
- 出参：
  - `vocab_id`

## 7. 跨平台截图与权限策略

### 7.1 macOS

- 截图：`ScreenCaptureKit` 或平台插件
- 权限：首次请求「屏幕录制」权限
- 风险：权限被拒绝时要有明显引导和重试入口

### 7.2 Windows

- 截图：`Windows Graphics Capture`（优先）或兼容实现
- 权限：通常无需类似 mac 的系统级弹窗，但应处理多显示器与 DPI
- 风险：窗口缩放比例导致区域坐标偏移

---

## 8. 安全与隐私

- 全部默认本地处理，不上传图片和字幕文本
- localhost API 校验来源（扩展固定 origin + token）
- 截图文件存于应用私有目录，支持手动清理
- 生词本数据可导出（JSON/CSV）但需显式触发

---

## 9. 打包与发布策略

### 9.1 Desktop（Tauri）

- macOS：`dmg` / `app`
- Windows：`msi` / `exe`

### 9.2 Sidecar（Python）

- 开发期：直接 `python -m uvicorn app.main:app`
- 发布期：`PyInstaller` 打单文件可执行，跟随桌面应用分发

### 9.3 浏览器插件（B 站）

- 开发期：`pnpm build` 生成 MV3 包
- 发布期：打包 zip，支持手动加载；后续上架 Chrome Web Store/Edge Add-ons

---

## 10. 实施顺序（建议）

1. 先跑通 desktop + sidecar：截图 -> OCR -> 分词 -> 入库  
2. 接入 JMDict，完善查词与词义存储  
3. 加入 B 站扩展，保存播放上下文并支持一键回看  
4. 优化 OCR 区域、去重、批量导出和复习功能  
5. 完善打包签名、自动更新、崩溃日志与埋点（可选）
