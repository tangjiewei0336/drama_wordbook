# Drama Wordbook 快速启动教程

本教程用于在本地快速跑通整套流程：  
**B站视频 -> 快捷键截图识别 -> 选词入库 -> 统计页查看剧照和释义**。

## 1. 前置要求

- macOS 或 Windows
- Chrome 浏览器（建议最新版）
- Python 3.11+

## 2. 启动 sidecar（本地服务）

在项目根目录执行：

```bash
cd apps/sidecar
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -e .
uvicorn app.main:app --host 127.0.0.1 --port 17321 --reload
```

默认启动不会下载 ASR 模型，避免网络不稳定时卡住 OCR/分词主流程。只有点击插件里的 `开始语音识别` 时，才会按需加载模型。

验证是否成功：

- 打开 `http://127.0.0.1:17321/health`
- 返回 `{"status":"ok", ...}` 即正常

## 3. 加载浏览器插件

1. 打开 `chrome://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择目录：`extensions/bilibili`

## 4. 首次建议设置

点击插件图标 -> `设置`，建议先确认：

- 勾选：`仅保留视频下半区（字幕带）`
- 勾选：`固定双语布局（上半中文，下半日语）`
- `上下分割比例` 先用默认 `0.7`
- 快捷键（页面内）：
  - mac 推荐：`Command + E`（如冲突改 `Command + Shift + S`）
  - Windows 推荐：`Ctrl + Shift + S`

## 5. 触发识别并添加词条

1. 打开任意 B 站视频页面并播放
2. 触发方式二选一：
   - 按快捷键
   - 插件弹窗点 `手动截图识别`
3. 页面会自动暂停并弹出词条面板
4. 多选字符/词片段，自动拼接最终词（可手动改）
5. 看实时词典提示（读音/释义）
6. 点击 `添加到词典`

## 6. 在桌面端查看和设置

打开 UNI 桌面端后，可查看：

- 按剧集整理：按番剧/剧集聚合词条，搜索会匹配剧集、词条、释义和例句
- 按时间整理：按保存日期浏览
- 句子项目：查看、编辑、朗读、分析、分享或删除句子
- 复习冲刺：选择题、读音题、连词成句，支持跳过和中止，完成后显示统计
- 设置：个人信息、导出生词本、OCR 修正、登录同步、桌面提醒、运行中心

### 6.1 OCR 大模型修正

桌面端进入 `设置 -> OCR 修正`：

- 开启 `启用大模型修正`
- 填入智谱 API Key
- 选择模型：`GLM-4.7` 或 `GLM-4.7-FlashX`

开启后，插件识别流程会在 `/ocr/recognize` 之后调用 `/ocr/correct`。修正结果会返回浏览器弹窗，并用于后续分词、展示和保存。该调用不启用思考模式。

注意：字幕自动模式不会调用大模型修正，只使用本地 OCR 清洗与分词，避免后台自动识别被网络请求卡住。

### 6.2 导出

桌面端进入 `设置 -> 导出生词本`：

- 可选择开始/结束日期
- 支持导出 PDF：按剧集排版，包含读音、音调、词性、例句和小剧照
- 支持导出 Excel：包含生词和句子工作表

### 6.3 运行中心

桌面端进入 `设置 -> 运行中心`：

- 查看 Sidecar 状态
- 下载/修复 OCR 模型
- 下载/加载 ASR 模型
- 切换 hf-mirror
- 查看日志、暂停滚动、清空日志

## 6.4 连续语音识别（PoC）

插件弹窗新增两个按钮：

- `开始语音识别`：从当前页面的 `<video>` 音轨采集音频，每 60 秒发送一次到 sidecar 转写
- `停止语音识别`：停止采集和转写

说明：

- 当前 PoC 默认识别语言为日语（`ja`）
- 结果会显示在弹窗顶部的 ASR 列表中
- 第一次开始语音识别时，`faster-whisper` 会下载模型权重，终端出现下载日志属于正常现象
- 如果下载失败，可手动指定镜像和缓存目录后重启 sidecar：

```bash
ASR_HF_ENDPOINT=https://hf-mirror.com ASR_MODEL_DOWNLOAD_ROOT=.models \
  uvicorn app.main:app --host 127.0.0.1 --port 17321 --reload
```

- 暂未做“背景音乐分离”，先用于准确率验证

## 7. 常见问题

### Q1: 快捷键没反应

- 先刷新扩展，再刷新 B 站页面
- 换用 `Command + Shift + S`（mac）
- 或直接点 `手动截图识别`

### Q2: 词典查不到

- 确认 sidecar 已重启到最新代码
- 在终端看 sidecar 是否有报错

### Q3: 统计页没有图片

- 必须先完成一次“添加到词典”
- 截图是保存到 sidecar 本地目录，不会上传到 git

### Q4: Windows 上 OCR 模型损坏或用户路径有中文

- 打开桌面端 `设置 -> 运行中心`
- 点击 `修复 OCR 模型`
- 应用会删除异常模型缓存并重新下载
- 打包版会尽量把 Paddle 模型缓存放到不含中文的可写目录

## 8. 重启最短路径（下次使用）

只需两步：

1. 启动 sidecar

```bash
cd apps/sidecar
source .venv/bin/activate
uvicorn app.main:app --host 127.0.0.1 --port 17321 --reload
```

2. Chrome 中确保扩展已加载，然后直接用快捷键触发
